# The Verge — Milestone 0.8

## Pilot readiness foundation

This milestone moves the local-first prototype toward real-user workflow testing.

### Included
- First-run workspace setup (business/activity name, industry, first location).
- Persisted active workspace metadata.
- Real local organization and location records.
- Dynamic workspace/branch display instead of hard-coded branch data.
- Personal finance local accounts and expenses.
- Product registration and stock receiving.
- Barcode/SKU-ready product model.
- Offline sales and inventory event records.
- Accounting chart foundation.
- Data export foundation.
- Consent/access foundation.
- Responsive mobile/desktop interface.

### Verification
- Domain test suite: PASS.
- TypeScript/JSX syntax transpilation check: PASS.
- Full dependency-based production build: not run in this environment because package installation could not complete within the available network/tool time.

### Not yet production-ready
- User authentication and account recovery.
- Server-side authorization/RLS equivalent on Neon.
- Neon sync API and conflict resolution.
- Multi-device live synchronization.
- Payment provider integration.
- Real POS hardware/scanner testing.
- Legal policy review.
- Security penetration testing.

These are deliberately tracked as gates rather than being represented as completed.
