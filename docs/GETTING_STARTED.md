# THE VERGE — Getting Started

THE VERGE is organized around a simple hierarchy:

**Business → Store / Branch → Inventory & Sales**

A **business** is the company or operation you manage. A **store / branch** is one physical selling location. A **warehouse** is a storage location. Inventory movements and sales are always recorded against the currently selected location.

## First-time setup

1. Open **Setup Guide** from the main navigation.
2. Open **Business** and review the business name and business type.
3. Under **Choose the store you are configuring**, select the first store or branch.
4. Complete **Set up [store name]**:
   - store / branch name
   - unique store code
   - location type
   - phone and optional email
   - address
   - receipt / trading name
   - receipt footer
5. Save the store setup.
6. Open **Inventory**:
   - add products
   - set cost and selling prices
   - enter barcode where available
   - receive the quantity physically available in the selected store
7. Open **Sales & POS** and complete the first transaction.
8. Return to **Setup Guide**. The core checklist should show all five steps complete.

## Adding another store

Go to **Business → Add another store, branch or warehouse**. Give it a unique code, create it, then select the new location and complete its store setup.

The location selector in THE VERGE determines where inventory and sales are recorded. Always confirm the selected store before receiving stock or selling.

## Where each feature lives

- **Overview** — setup progress and daily command center.
- **Business** — business profile, stores/branches, customers and operating expenses.
- **Inventory** — products, prices, barcodes, receiving and restocking.
- **Sales & POS** — cart, customer, payment method, completed sales and sale reversals.
- **Accounting** — journals and financial records created from verified business activity.
- **Settings** — privacy, exports, API credentials and advanced access controls.

## Offline behavior

Day-to-day inventory and sales are designed to keep working locally when connectivity drops. Business/store configuration is server-backed, so changing the business profile or adding/configuring a store currently requires an internet connection.

When the connection returns, queued operational changes synchronize with the server instead of silently overwriting one another.
